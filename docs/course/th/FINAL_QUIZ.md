# แบบทดสอบท้ายหลักสูตร

**เวลา:** 3 นาที
**เกณฑ์ผ่านที่แนะนำ:** 8 จาก 10 ข้อ

1. ผลที่ Technical Crawl ยืนยันได้ดีที่สุดคืออะไร
   - ก. อันดับหนึ่ง
   - ข. หลักฐานทางเทคนิคภายใน Scope ที่ตั้งไว้
   - ค. ยอดขายที่เพิ่มขึ้น

2. ASO ในคอร์สนี้หมายถึงอะไร
   - ก. AI Search Optimization
   - ข. App Store Optimization
   - ค. Automatic Site Output

3. `limit_reached` บอกอะไร
   - ก. Crawl จบครบทั้งเว็บ
   - ข. URL Ceiling หยุด Crawl ก่อนงานใน Scope จบ
   - ค. ไม่มี Finding

4. ทำไม Scope และ Configuration ต้องอยู่ในรายงาน
   - ก. เพราะค่าที่ต่างกันทำให้ Coverage และผลลัพธ์ต่างกัน
   - ข. เพราะใช้รับประกันอันดับ
   - ค. เพราะแทน Evidence ได้

5. ข้อใดเป็นการเปรียบเทียบ Toad ที่ยุติธรรม
   - ก. มี Feature เท่ากับ Screaming Frog ทุกอย่างแล้ว
   - ข. ครอบคลุมงานหลักจำนวนมากและเด่นด้าน Open Source กับ MCP แต่ยังมี Feature Gap
   - ค. เป็นผลิตภัณฑ์ของ Screaming Frog Ltd

6. Sitemap ทำหน้าที่ใด
   - ก. ช่วย Discovery และส่งรายการ URL แต่ไม่รับประกัน Index
   - ข. รับประกันอันดับ
   - ค. ใช้แทน Canonical

7. MCP ช่วยอะไร
   - ก. ให้ AI Client เรียกเครื่องมือ Crawler ที่จำกัดขอบเขตผ่านมาตรฐานร่วม
   - ข. ปิด Security Guard ทั้งหมด
   - ค. เปิดฐานข้อมูล Audit ให้สาธารณะ

8. ก่อน Agent เริ่ม Crawl ต้องยืนยันอะไร
   - ก. สิทธิ์ในการตรวจ Scope Exclusion และ Limit
   - ข. ว่า URL Ceiling เป็น Unlimited
   - ค. ว่าจะได้อันดับหนึ่ง

9. คำกล่าวเกี่ยวกับ 100M+ ที่ถูกต้องคือข้อใด
   - ก. เป็น Live Capacity ที่รับรองแล้ว
   - ข. เป็นเป้าหมายเชิงสถาปัตยกรรมแบบ Segment ที่ยังไม่ผ่านการยืนยัน
   - ค. เป็นจำนวนที่ UI แสดงจึงถือว่าพิสูจน์แล้ว

10. หลังแก้ Code ควรทำอะไร
    - ก. ปิด Finding ในรายงานเอง
    - ข. Test, Deploy อย่างปลอดภัย, Crawl ซ้ำ และตรวจ Evidence เปรียบเทียบ
    - ค. ลบ Crawl เดิม

## เฉลย

1-ข, 2-ก, 3-ข, 4-ก, 5-ข, 6-ก, 7-ก, 8-ก, 9-ข, 10-ข

## งานปฏิบัติขั้นต่ำ

ให้ผู้เรียน Crawl เว็บไซต์ที่ตนเองเป็นเจ้าของหรือได้รับอนุญาต แล้วส่งข้อมูลต่อไปนี้

- Seed, Scope, URL Ceiling, Mode และ Terminal State
- Finding หนึ่งรายการพร้อม Rule ID และ Evidence
- วิธีแก้ที่เสนอ และขั้นตอน Recrawl เพื่อยืนยันผล
