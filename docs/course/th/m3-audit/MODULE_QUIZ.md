# แบบทดสอบท้ายโมดูล 3

**เวลา:** 2 นาที

1. สถานะ `limit_reached` หมายถึงอะไร
   - ก. Crawl ครบทั้งเว็บแล้ว
   - ข. เพดาน URL หยุดงานก่อน Frontier จบ
   - ค. ทุกหน้ามี Error

2. ทำไมต้องเก็บ Raw และ Rendered แยกกัน
   - ก. เพื่อเห็นสิ่งที่ Server ส่งมาเทียบกับผลหลัง JavaScript ทำงาน
   - ข. เพื่อเพิ่มจำนวน Warning
   - ค. เพื่อข้าม Robots

3. ข้อใดถูกต้อง
   - ก. Sitemap รับประกันการ Index
   - ข. Valid JSON-LD รับประกัน Rich Result
   - ค. robots.txt, noindex, Canonical และ Sitemap มีหน้าที่ต่างกัน

**เฉลย:** 1-ข, 2-ก, 3-ค
