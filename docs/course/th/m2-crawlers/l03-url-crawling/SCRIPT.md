# บทที่ 3 — URL Crawler ทำงานอย่างไร และทำไมคนใช้ Screaming Frog

**เวลาเป้าหมาย:** 4 นาที

## บทพูด

[ภาพบนจอ: URL ตั้งต้น → โหลดหน้า → ดึงลิงก์ → ตรวจ Scope → ใส่คิว]

ถ้าอยากเข้าใจเว็บไซต์ทั้งระบบ เราเปิดดูทีละหน้าเองไม่ได้ โดยเฉพาะเว็บที่มีหลักพันหรือหลักหมื่น URL เราจึงใช้ Crawler เป็นตัวเดินสำรวจ

Crawler เริ่มจาก Seed URL หนึ่งหน้า เมื่อโหลดเสร็จจะบันทึก Status Code, Metadata และลิงก์ที่พบ จากนั้นจัดรูป URL ให้เป็นมาตรฐาน ตัดรายการซ้ำ ตรวจว่าอยู่ใน Scope หรือไม่ แล้วนำ URL ที่ผ่านไปใส่คิวซึ่งเรียกว่า Frontier กระบวนการนี้ทำซ้ำจนคิวหมดหรือชน Limit ที่เราตั้งไว้

ผลที่ได้ไม่ใช่เพียงรายชื่อหน้า แต่เป็นแผนที่ความสัมพันธ์ของเว็บไซต์ เราจึงเห็นว่าหน้าใดลิงก์ไปหน้าเสีย หน้าใดอยู่ลึกเกินไป Redirect ต่อกันหลายทอดหรือไม่ และ Sitemap กำลังส่ง URL ที่ขัดกับ Canonical หรือเปล่า

Crawler ที่รับผิดชอบต้องควบคุมความเร็ว เคารพ `robots.txt` จำกัดจำนวนงานต่อ Host ป้องกัน URL Trap และหยุดได้อย่างปลอดภัย การยิง Request ให้เร็วที่สุดไม่ใช่ความเก่ง ถ้าทำให้ Server ของคนอื่นมีปัญหา

[ภาพบนจอ: Screaming Frog SEO Spider 24.3 ที่ติดตั้งในเครื่อง พร้อมข้อความว่าไม่มีความเกี่ยวข้องกับโครงการ Toad]

Screaming Frog SEO Spider เป็นโปรแกรม Desktop ที่ผู้เชี่ยวชาญ Technical SEO ให้ความเชื่อถือ เพราะพัฒนามานาน ปรับแต่ง Crawl ได้ละเอียด มี JavaScript Rendering, Custom Extraction, Scheduling, Integration และระบบ Export ที่คุ้นเคย

เวอร์ชันฟรีจำกัด 500 URL ส่วนราคาฐานที่ตรวจสอบตอนทำคอร์สคือ 199 ปอนด์ต่อผู้ใช้ต่อปี โดยราคาสกุลอื่นอาจเปลี่ยนตามอัตราแลกเปลี่ยน

เหตุผลที่เรานำมาเปรียบเทียบไม่ใช่เพื่อโจมตี แต่เพื่อให้ผู้เรียนรู้ว่ามาตรฐานของเครื่องมือมืออาชีพควรให้ข้อมูลที่ตรวจสอบย้อนกลับและนำไปทำงานต่อได้จริงครับ
