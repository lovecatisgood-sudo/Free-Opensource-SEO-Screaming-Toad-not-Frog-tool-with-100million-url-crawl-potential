# Final Course Quiz

**Target duration:** 3 minutes
**Recommended passing score:** 8 out of 10

1. SEO helps search systems:
   - A. Discover and understand useful website content
   - B. Guarantee first position
   - C. Ignore website quality

2. In this course, ASO means:
   - A. App Store Optimization
   - B. AI Search Optimization
   - C. Automated Site Output

3. A `limit_reached` crawl is:
   - A. Complete
   - B. Incomplete because its URL ceiling stopped it
   - C. Guaranteed error-free

4. Why inspect raw and rendered evidence?
   - A. To compare server output with JavaScript-produced output
   - B. To bypass crawler rules
   - C. To guarantee indexing

5. Which statement is true?
   - A. A sitemap guarantees indexing
   - B. Canonical, robots.txt, noindex, and sitemap serve different purposes
   - C. Valid JSON-LD guarantees rich results

6. Toad compared with Screaming Frog:
   - A. Has proven complete parity
   - B. Covers many core audit workflows but has mature-feature gaps
   - C. Is affiliated with Screaming Frog Ltd

7. MCP lets an AI client:
   - A. Call bounded crawler tools through a standard interface
   - B. Guarantee rankings
   - C. Disable every safety control

8. Before starting an MCP crawl, confirm:
   - A. Authorization, scope, exclusions, and limits
   - B. That the URL ceiling is unlimited
   - C. That the server is publicly exposed

9. The approved 100M+ statement describes:
   - A. Verified live capacity
   - B. Theoretical segmented architecture potential
   - C. Guaranteed laptop performance

10. The strongest fix workflow is:
    - A. Change code and assume success
    - B. Find root cause, test, deploy safely, recrawl, and inspect comparison evidence
    - C. Delete all warnings from the report

## Answer key

1-A, 2-B, 3-B, 4-A, 5-B, 6-B, 7-A, 8-A, 9-B, 10-B.

## Minimum practical completion

The student should also complete one authorized crawl and submit:

- the seed, scope, URL ceiling, rendering mode, and terminal state;
- one finding with its rule ID and representative evidence;
- one recommended fix and a clear recrawl verification step.
