# Module 3 Rapid Quiz

**Target duration:** 2 minutes

1. What does `limit_reached` mean?
   - A. The entire site was audited
   - B. The configured ceiling stopped the crawl
   - C. Every page ranked

2. Why keep raw and rendered evidence separate?
   - A. To distinguish the server response from the JavaScript-produced document
   - B. To double the warning count
   - C. To bypass robots rules

3. Which statement is correct?
   - A. Sitemap inclusion guarantees indexing
   - B. Robots.txt, noindex, canonical, and sitemap have different purposes
   - C. Valid JSON-LD guarantees a rich result

**Answers:** 1-B, 2-A, 3-B.
