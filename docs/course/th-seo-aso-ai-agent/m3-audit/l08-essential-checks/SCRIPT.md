# บทที่ 8 — Checklist สำคัญสำหรับ SEO และ AI Search

**เวลาเป้าหมาย:** 5 นาที

## บทพูด

[ภาพบนจอ: Technical SEO Checklist แบบเคลื่อนไหว]

บทนี้เราจะจัดกลุ่มสิ่งที่ Crawler ตรวจให้เข้าใจง่าย เริ่มจาก Response ก่อน หน้า 200 หมายถึงรับเนื้อหาได้ Redirect ต้องดูว่าพาไปจุดหมายถูกหรือวนหลายทอด ส่วน 404 ไม่ได้ผิดเสมอ ถ้าเป็น URL ที่เลิกใช้งาน แต่ถ้าเมนูหลักยังลิงก์ไป 404 นั่นคือปัญหา

กลุ่มต่อมาคือ Title, Meta Description และ H1 หน้าที่สำคัญควรบอกหัวข้อได้ชัด ไม่ใช้ข้อความซ้ำโดยไม่มีเหตุผล แต่เกณฑ์ความยาวเป็นคำแนะนำด้านการเขียน ไม่ใช่กฎจัดอันดับตายตัว

[ภาพบนจอ: robots.txt, noindex, Canonical และ Sitemap แยกเป็นสี่ช่อง]

สี่คำนี้มักถูกสับสน `robots.txt` ใช้กำกับการเข้าถึงของ Crawler ส่วน `noindex` บอก Search Engine ว่าไม่ต้องนำหน้าไป Index Canonical ชี้หน้าตัวแทนที่ต้องการในกลุ่มเนื้อหาคล้ายกัน และ Sitemap ช่วยส่งรายการ URL สำคัญ Sitemap ไม่รับประกันการ Index และ Canonical ก็เป็นสัญญาณแนะนำ ไม่ใช่คำสั่งเด็ดขาด

Duplicate และ Near-duplicate ช่วยหาหน้าที่คล้ายกันมาก แต่หน้าสินค้าหรือเครื่องมือในตระกูลเดียวกันย่อมมีส่วน Template ซ้ำ ต้องให้คนตัดสินว่ามี Search Intent แยกกันจริงหรือไม่

Hreflang เชื่อมหน้าภาษาและภูมิภาค ควรใช้ Code ถูกต้อง ชี้ไปยัง URL ที่เข้าได้และลิงก์กลับหากัน รูปภาพต้องแยกให้ออกระหว่างภาพที่มีความหมายกับภาพตกแต่ง ไม่ควรยัด Keyword ลง Alt ทุกภาพ

Structured Data ช่วยอธิบายข้อมูลให้เครื่องเข้าใจ แต่การผ่าน Syntax ไม่ได้แปลว่าจะได้ Rich Result และข้อมูลต้องตรงกับสิ่งที่ผู้ใช้มองเห็นเสมอ

[ภาพบนจอ: พื้นฐาน AI Search = Crawl ได้ + โครงสร้างชัด + เนื้อหาต้นฉบับ + หลักฐาน]

สำหรับ AI Search สิ่งสำคัญยังเป็นพื้นฐานเดียวกัน เพิ่มด้วยข้อมูลต้นฉบับ ประสบการณ์จริง ตัวอย่าง และแหล่งอ้างอิงที่ชัด Toad ตรวจเงื่อนไขทางเทคนิคได้หลายส่วน แต่ไม่ได้ตัดสินคุณภาพบทความแทนเรา

สุดท้ายให้จัด Priority จาก Impact, Confidence และจำนวนหน้าที่ได้รับผล อย่าแก้ตามสีเพียงอย่างเดียวครับ
