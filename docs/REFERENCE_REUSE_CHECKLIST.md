# Reference-reuse checklist

Before adapting code or fixtures from another repository:

1. Record the repository URL, exact commit and license.
2. Confirm the license permits the intended use and distribution.
3. Prefer behavioural inspiration and an independent implementation.
4. If source is reused, identify each file and retain required notices.
5. Review the adapted code against SEO Auditor's current security boundaries.
6. Add independent positive, negative and adversarial tests.
7. Update `THIRD_PARTY_NOTICES.md` and the dependency/license inventory.
