## Short launch post

🐸 Meet **SEO Screaming Toad — Not Frog**, a free open-source technical SEO crawler built in Go.

It combines a dense local audit dashboard, raw and JavaScript-rendered evidence, versioned SEO checks, crawl comparison, recoverable jobs, CSV/NDJSON/XLSX reports, and a 23-tool MCP server that lets AI agents operate bounded audits.

It is designed toward theoretical 100M+ URL segmented campaigns, but we are deliberately not presenting that as verified live capacity. The current release candidate is for people who want an inspectable, local-first Screaming Frog alternative and want to help improve it.

## Longer community post

I wanted a technical SEO crawler whose networking rules, audit evidence, storage, and automation interface could all be inspected. SEO Screaming Toad runs locally, uses a guarded Go crawler and SQLite/WAL persistence, distinguishes raw HTML from JavaScript-rendered evidence, and provides versioned SEO findings with explicit limitations.

The unusual part is the MCP server: an AI agent can create a bounded crawl profile, preview scope, control the crawl, inspect pages/links/issues, compare runs, and create managed reports without receiving a generic shell or unrestricted HTTP tool.

The segmented architecture is intended to support campaigns beyond 100 million URLs, but that remains theoretical rather than verified live-network capacity. Today the project has passed a 100,000-URL crawl gate and synthetic persistence/analysis campaigns at 1 million and 5 million URLs.

I would especially value feedback from technical SEOs on false positives, missing evidence, crawl compatibility, and the workflows an open-source alternative should prioritize.
